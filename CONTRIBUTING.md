# Panduan Kontribusi (Contributing Guidelines)

Terima kasih telah tertarik untuk berkontribusi pada proyek **Vape Store Retail - POS & Inventory System**.

## Cara Berkontribusi

1. **Fork** repositori ini ke akun GitHub Anda.
2. **Clone** repositori yang telah di-fork ke komputer lokal Anda.
3. Buat branch baru untuk fitur atau perbaikan *bug* Anda (`git checkout -b fitur-baru`).
4. Pastikan Anda telah menginstal dependensi (`npm install`).
5. Buat perubahan pada kode Anda. Pastikan kode berjalan dengan baik (`npm run dev`).
6. Lakukan *commit* dengan pesan yang jelas (`git commit -m "Menambahkan fitur X"`).
7. Lakukan *push* ke repositori Anda (`git push origin fitur-baru`).
8. Buat **Pull Request (PR)** dari branch Anda ke branch utama (`main`) di repositori ini.

## Standar Kode
- Gunakan standar penulisan kode modern untuk React dan TypeScript.
- Hindari penggunaan `any` sebisa mungkin dalam TypeScript.
- Pastikan tampilan responsif karena aplikasi ini ditujukan untuk digunakan di Desktop maupun Mobile.

Terima kasih atas bantuan Anda membuat sistem Kasir & Inventaris ini menjadi lebih baik!
